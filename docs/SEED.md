# Master Seed Data UUIDs

The project uses fixed UUIDs for seed data across all tests and local development.
Format: `00000000-0000-0000-TTTT-0000000000NN`

- `0001` - Districts
- `0002` - River Basins
- `0003` - Hazard Types
- `0004` - Organisations
- `0005` - Relief Items
- `0006` - Users
- `0007` - Events
- `0008` - Sensors
- `0009` - Shelters
- `0010` - Rescue Teams
- `0011` - Relief Stock
